# 🌀 Origin Portal

**Origin Portal** is the official platform of **Origin Dev Group** — a central hub for innovation, AI, and software development.  
It connects projects, tools, and research into one modern, minimal interface where ideas begin and technology evolves.

---

## 🚀 Project Overview
Origin Portal serves as the main entry point to the Origin Dev Group ecosystem.  
This project focuses on building a visual, modular, and scalable **frontend** using **Vue.js 3** and **Vite**.

---

## 🧰 Tech Stack
- ⚙️ **Framework:** [Vue.js 3](https://vuejs.org/)
- ⚡ **Build Tool:** [Vite](https://vitejs.dev/)
- 🎨 **Styling:** [TailwindCSS](https://tailwindcss.com/) *(optional, for future styling)*
- ☁️ **Deployment:** GitHub Pages / Netlify

## ⚙️ Installation Guide

### 1️⃣ Install Node.js
Download and install the **LTS** version of Node.js from:  
👉 [https://nodejs.org](https://nodejs.org)

To verify the installation, run in your terminal:
```bash
node -v
npm -v
````

---

### 2️⃣ Clone the Repository

```bash id="n5o8j3"
git clone https://github.com/Origin-Dev-Group/origin-portal.git
cd origin-portal
```

---

### 3️⃣ Install Dependencies

```bash id="q93e3f"
npm install
```

This will install all required packages defined in `package.json`.

---

### 4️⃣ Run the Development Server

```bash id="kqvcoi"
npm run dev
```

Then open the provided local URL (usually:
👉 [http://localhost:5173](http://localhost:5173))
to view the app in your browser.

---

### 5️⃣ Build for Production (optional)

When you’re ready to deploy:

```bash id="psf9dm"
npm run build
```

This generates the optimized static files in the `/dist` folder.

## 🤝 Contributing

We welcome contributions from the community to improve **Origin Portal** and the broader **Origin Dev Group** ecosystem.

### 🔹 How to Contribute

1. **Fork** the repository

   ```bash
   git fork https://github.com/Origin-Dev-Group/origin-portal.git
   ```
2. **Clone** your fork

   ```bash
   git clone https://github.com/your-username/origin-portal.git
   cd origin-portal
   ```
3. **Create a new branch** for your feature or fix

   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make your changes** and commit

   ```bash
   git add .
   git commit -m "feat: describe your change"
   ```
5. **Push your branch**

   ```bash
   git push origin feature/your-feature-name
   ```
6. **Open a Pull Request (PR)** to the `main` branch of this repository.

### 💡 Contribution Guidelines

* Follow the existing **code structure** and **naming conventions**.
* Keep commits **clear and concise**.
* Reference issues in your PR descriptions when applicable.
* Be respectful and collaborative — our goal is to build together.
